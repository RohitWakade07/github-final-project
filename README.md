# Simple Interest Calculator

A simple interest calculator written in bash script.

## Introduction

This is a simple interest calculator that computes the simple interest based on user input.

## What is Simple Interest?

Simple interest is calculated using the formula:

**SI = (P x R x T) / 100**

Where:
- **P** = Principal amount
- **R** = Rate of interest (per annum)
- **T** = Time period (in years)

## Usage

Run the script and provide:
1. Principal amount
2. Rate of interest
3. Time period in years
